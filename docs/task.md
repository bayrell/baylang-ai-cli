Создай tools для файловой системы: поиск файла, список, создание, удаление, переименовывание, редактирование, regexp в рабочей директории cwd. При этом AI не должен получить доступ ко всей фс.

Файлы для tools должна быть в одной папке. Один файл на каждый при этом в файле класс ООП. В каждом классе должна быть функция format_message, для format_display.
